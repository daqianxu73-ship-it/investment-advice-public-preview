# 确认偏离从何而来

偏离可能来自上涨后占比被自然抬高，也可能来自当初的主动选择。前者是市场结果，后者是偏好与目标的差距，处理对象完全不同。

# 梳理客观约束

先看几项事实：是否已越过赎回费阶梯、近期是否有资金支用计划、账户有无待到账资金。这些不涉及判断，却决定可行路径。

# 留意常见的心理陷阱

处置效应：人们倾向卖出盈利、留住亏损：前者兑现“我是对的”，后者推迟承认亏损。
锚定成本价：买入价与未来表现无关，但“回本”常被当作行动前提，因而迟迟不动。
